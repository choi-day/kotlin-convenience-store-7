### 구현할 기능 목록

- 입력
    - [x] 구매할 내역 입력받기
- 출력
    - [x] 환영인사 출력
    - [x] 상품명, 가격, 프로모션 이름, 재고 안내
    - [ ] 영수증 출력
      - [ ] 총구매액
      - [ ] 행사할인
      - [ ] 멤버십 할인
      - [ ] 내실 돈
- 기능
  - 프로모션
    - [ ] 오늘 날짜를 받아 할인 적용 여부 결정
    - [ ] 1+1, 2+1 혜택 확인 
    - [ ] 프로모션 재고가 가져온 수량보다 많은지 확인
    - [ ] 일반 재고 사용 여부 결정
    - [ ] 프로모션 재고가 적은 경우 정가 결정 안내
    - [ ] 프로모션에 해당하는 수량보다 적게 가져온 경우 혜택 안내

  - 재고 관리
    - [ ] 각 상품의 재고를 고려하여 결제 가능 여부 결정
    - [ ] 고객이 상품 구매시 재고 차감
  
  - 멤버십
    - [ ] 멤버십 회원은 프로모션 미적용 금액의 30%를 할인받음
    - [ ] 멤버십 할인의 최대 한도는 8,000원
